# AdigunAiAutoCad Help

## Using the Adigun BOT Floating Window

Select the floating Adigun BOT button to open or close the copilot. On desktop, drag the window by its title area, resize it from the lower-right corner, or use the minimize and maximize controls. Select the launcher to restore a minimized window. Press the arrow keys while the title area is focused to move the window; hold Shift to move it farther. Press Escape to close the open window. On a small screen, the window uses the available screen area.

The window's open state, size, position, and minimized or maximized state are saved in this browser on this device. Those preferences are not synchronized to a cloud account. Conversation messages remain in memory only and are cleared when the page reloads.

The Adigun BOT can answer questions about this CAD workspace and electrical drawing concepts. It cannot inspect or edit the current drawing, account data, or project files, and it cannot create or validate CAD objects. Verify engineering decisions against the actual drawing and applicable technical sources.

The BOT sends only the text you submit and the selected interface language to its product endpoint. If the service is unavailable, the interface reports that instead of inventing a result.
